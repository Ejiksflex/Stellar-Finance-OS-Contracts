# bindings

Generated TypeScript clients for each contract. **Do not edit by hand.**
Regenerate with `./scripts/bindings.sh` after any public interface change.

| Directory | Contract |
|---|---|
| `approval-vault/` | `contracts/approval-vault` |
| `invoice-registry/` | `contracts/invoice-registry` |

Consumed by `finance-os-backend` (`packages/stellar`) and `finance-os-web` (`packages/wallet`).
Pair them with the contract IDs in `../deployments/<network>.json`.
